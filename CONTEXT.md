# CONTEXT — kerby-web domain glossary

- **checkpoint** — an illustrated condition, action, evidence, responsibility and response when unmet.
- **Agent instruction** — behavior the loaded rulebook asks the agent to follow.
- **Hook check** — a specific script check at a supported tool boundary, when installed. Blocking and warning outcomes differ.
- **Your decision** — human intent, approval or review where the workflow requires it.
- **Held** — an editorial state for work lacking evidence to advance; not an invented transcript.
- **transcript** — exact source output, checked against README at the pinned Kerby commit.
- **illustrative example** — invented scenario content demonstrating the method, with no actual execution claim.
- **source pin** — KERBY_REF in deploy.yml, shared by transcript and SWE fact checks.
- **base path** — root on the custom domain; project-base deployment remains supported through src/lib/url.ts.
- **accent-as-mark** — terracotta as an underline, state mark or link, never an area fill.
